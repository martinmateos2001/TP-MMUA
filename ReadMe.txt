Para que todos trabajemos con el mismo entorno/kernel ejecuten el siguiente comando: conda env create -f LaboratorioDeDatos.yml
Pueden actualizar el entorno con: conda env update -f environment.yml --prune
Pueden activar el entorno en sus propias terminales con: conda activate LaboratorioDeDatos
Antes de ejecutar algo en el archivo ipynb recuerden seleccionar el kernel LaboratorioDeDatos
